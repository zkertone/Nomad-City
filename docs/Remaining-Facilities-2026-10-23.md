## 结算时序与存档

继续使用同一服务器权威GameState，以及原有余额、棋盘标记、实体归属和面板位置。没有复制账本、客户端写入接口、通用事件总线或更换核心架构。按现有仓库父子进度扩展局部设施继续结算，显式调用 `enableNestedFacilityEntries(state, definition, {expectedVersion})` 将1.11.0升级为1.12.0；更早格式先依次使用既有升级，不能猜测旧历史。

1.12.0新增construction.entryStack及roundFlow.startingPlayerOverride。后者必须显式为null或实际拥有的联邦理事处/玩家引用，回合收尾消费并清空。entryStack仅保存效果来源牌、待选/等待子步骤，以及需要的探索/移城进度，不另存余额、标记或实体副本。

父建设仍只消耗当前一次主要行动：constructionsCompleted=1和builtCardId始终描述原设施，子设施不另开额度。每次成功玩家命令只使全局stateVersion加1；每次实际拿普通牌建设按原规则各更新库存/面板revision并立即补牌。建设已提交后，错误子选择不会撤销已合法完成的付款、补牌、摆放或分数，也不会提交错误子步骤的局部变化。

所有新设施以entryChoice `{kind:'deferred-entry'}` 开始，先支付→取牌并补牌→摆放→得分，然后才让玩家选择入场。1.12.0中的旧设施也可使用此方式，让额外建设的开采电铲等在子补牌公开后再决策；原有自愿预选并一次完成的接口保持兼容。没有入场或确定性奖励自动执行；无需伪造无意义的确认步骤。

旧1.11.0仓库的待分支/待事件/待放置可原样升级，继续使用applyWarehouseEntryCommand。该路径和新entryStack不能同时拥有同一次建设。恢复只解析已保存的真实进度，不重扣建设费、重抽事件或重发奖励。

## 权威继续命令

正式入口是 `applyNestedFacilityEntryCommand(state, definition, {authenticatedPlayerId}, payload)`，每条payload含gameId/expectedVersion。玩家只提供下列选择，不提供actorId、费用、免费标志、得分、下一阶段、额外额度或结果状态。

| type | 玩家选择 | 对应待结算效果 |
| --- | --- | --- |
| build-logistics-extension | placement:null，或{cardId,cellId} | 物流可选的延伸建设 |
| construct-entry-facility | cardId/cellId/paymentMode/entryChoice | 工程营的正常额外建设 |
| copy-facility-entry | targetCardId | 能源设施复制相邻非虹色设施 |
| resolve-facility-entry | entryChoice | 被复制/延后的资源分配、出售、影响力选择或仓库分支 |
| explore / choose-exploration-event / place-exploration-influence | 原有完整探索选择 | 仓库子探索，正常收路费 |
| move-city / choose-city-move-event / place-city-move-influence | 原有完整移城选择 | 动力系统的免费子移城 |
| place-entry-route-influence | slotId | 移城全部结束后，在实际经过航道放额外标记 |

`getNestedFacilityEntryOptions` 只读返回当前叶步骤允许的公开选择和目标；`getPendingFacilityEventRequirements`查询当前事件选项要求。正式命令按实际状态重新验证。待效果完成前不能结束回合、取消已执行建设、插入角色或再开主要行动。框架语法、父子来源、面板所有权、复制邻接、实际事件、移动路径和标记守恒均验证；这些检查不是对历史行为的密码学证明，服务器仍须持有权威存档，不能接受客户端整体状态覆盖。

## 六类效果的边界

物流：卡面明确“可”，因此placement:null合法。仅从extensionReserve选择1张，不从普通市场或牌堆选；黄色卡原图未印费用，按这张特殊牌自身的已拍卡面结算-1分，没有普通牌免单参数。占格或无效选择不改变已提交的物流。其他颜色继续拒绝。供应牌堆与普通市场不会因取预留延伸再次补牌。

工程营：建设图标没有“免费”，必须另付子牌的完整费用；不能先领子入场奖励垫付。仍检查唯一性、空格、真实市场、补牌及具体效果，允许选择刚补出的牌。没有可付费、可合法建造的已知候选时按p13跳过不可能步骤；如果原因含未拍颜色或补牌耗尽，保留规则缺口，不把未知误作不可执行而跳过。面板已满时确实无法再建，可自动结束。

能源设施：仅复制本人十字相邻、实际非虹色的设施；不复制卡片、不再次支付/拿牌/得印刷分数，也不重算目标的唯一建设限制。获得资源、出售、影响力操作、物流、仓库探索及动力移城均复用相应效果。目标没有入场效果时不凭空产生效果；例如城邦工业区的建设自折扣不能变成入场资源奖励。虹色工程营/理事处/能源自身和核心不可复制，不会形成无界复制递归。

动力系统：免除普通移城的3源石；城市移动不收探索路费。单一独立航道仍保留三/四端身份，目的地不得是本人原地、其他城市或未开放红区。先移动并精确清除所选航道/目标上的对手影响力，揭未探索点事件并结算，完成正常目标点末尾放置，之后才放额外航道影响力。已经探索的点不再抽旧事件。只能缺库存/满槽等真实不可能时跳过相应放置，不得提前把航道标记放入、凭空造标记或拆分分叉航道收费。

理事处：建设时只记录本回合最后一张的建造者，不立即改变当前顺序、起始玩家双角色权限或正在进行的行动。全员采集和已有雷蛇收尾义务完成后，才将原环形座次旋转到该玩家；不改变其他人的相对顺序。不同玩家可各建自己的唯一理事处，后建覆盖；记录只在本回合生效，下一回合恢复普通传递。角色在建设后使用并退休旧行动时，回合级记录仍保留。
