# 简化2D建设与设施入场 · 2026-10-28

基于main0174f7ff17ad8e6afcb73328d00c2f4827a5cbcb，延续负责人“下一步”、本地优先、提交main与共享2D／2.5D路线。复用原规则和存档，没有给旧局补造历史或自动升级。

## 页面范围

- 五种普通主要行动入口齐备。建设显示当前公开六张实体设施的名称／颜色／分数／效果，本人4行3列逻辑面板、已占用设施与可选空格；没有新几何规则。
- 玩家明确选择设施、资源组合或金券、空格，预览原报价及折扣／印刷分数；只有原完整命令验证通过才可确认。不能用入场收益垫付成本，唯一设施、版本和普通供应耗尽拒绝沿用原规则。
- 当前1.12及以后的支持格式统一提交原deferred-entry：先支付、拿牌并补牌、摆放与计分，之后等待真实入场选择。确定性效果由原引擎自动结算；每个玩家决定保存在原construction进度中，不提前略过。
- 仓库影响力分支在同一原指令内先放置再移动，可以移动刚放的标记；探索分支另开原子进度，复用原路径／路费／事件／末尾放置界面。无法执行时依原规则跳过，不发明新选项。
- 高性能动力系统的免费移城明确显示0费用，仍完成事件、目标点末尾标记及之后的额外航道标记；不能误收普通移城的3源石，也不能提前结束父建设。
- 物流枢纽明确选择剩余延伸枢纽与空格，或自愿不放置；复制只给出原工具允许的相邻非虹色设施；追加建设继续显示新供应并支付原费用，不消耗新的主要行动。
- 选择五资源分配、规定移除／替换、数量出售等沿用原指令。影响力下拉使用公开稳定槽位供填写草稿，**不是合法性担保**；完整草稿交给原reducer验证，无法执行时禁用确认并给出提示。没有客户端复刻另一套仓库放置／移动规则。

来源／目标、付款、分配、出售和分支均由本人确认。成功写入后仅从新视图显示下一步；主要行动完整结束仍须明确点击结束行动轮，角色／样式机会不会自动消耗。

## 只读协议

`room:action-options {roomId}` 增加construct开启权限与construction：真实面板格位、空格、公开设施、初始或额外建设来源、原工具的额外付款组合／复制对象／物流库存／附加航道槽位。仍限当前受管玩家本人，不给非操作者发入场选择，初始化pending不推进。

新增严格`room:construction-preview {roomId,channel,command}`，只接受construction、facility-entry和warehouse-entry三个原Schema；command保留原gameId／expectedVersion。查询沿用房间队列、可信成员与前后重新认证，拒绝额外身份、任意状态和其它通道。响应封套仍按roomId／gameId／stateVersion；匹配的当前construction阶段返回原指令草稿回显、execution固定合法／拒绝代码以及可用的原成本报价，其他人为null。

预览使用原applyConstructionCommand／applyNestedFacilityEntryCommand／applyWarehouseEntryCommand纯函数；候选状态立即丢弃，不写库、不推送、不恢复自动阶段。quote显式只取费用、原折扣、印刷分数、支付能力和入场要求，不发模拟补牌、牌堆顺序、成员表或对手暗牌。

确认走原room:command／三个既有通道，重新校验和CAS保存，逐接收者推送；预览不是提交授权替代，不自动重发超时写入。

## 嵌套旅行和兼容

TravelOptions带原拥有者channel与普通／免费费用；当前entryStack顶层或旧warehouseEntry决定事件要求、末尾槽位和执行通道，始终使用原核心查询及reducer。原完整路径报价引擎quoteExplorationStep新增公开导出，供可信服务对保存的子进度只读报价；**仅导出原函数，没有修改其规则或实现**。不构造另一份权威GameState或把子行动伪装成普通行动。

旧warehouseEntry的分支／已揭事件／末尾状态也可恢复；没有任何可执行探索时，原reducer核准无路径分支后才显示确认。较早格式仍可读，当前建设界面不会强制升级不支持deferred-entry的旧格式。城市样式授予的建设／搜索续接不在本批范围，不公开暗牌搜索或推断牌序。

## 客户端与边界

ConstructionPanel独立于棋盘，按gameId和确认版本重建；编辑草稿清空旧预览，异步结果须匹配房间／对局／版本和实际选择。严格Schema可能重排JSON对象字段，因此采用递归排序的选择键；数组顺序仍保留，改变移除顺序或任何选择都会令旧报价失效。

成功回执可能早于最新返回视图，后续继续以view版本提交。断线／失效／换房、拒绝和超时沿用原控制器保护。刷新丢弃未确认草稿，已确认建设、补牌和入场子进度从数据库恢复，不重做支付／加分／入场。

本批尚未接角色／城市样式、采集、雷蛇清理、终局操作页面或2.5D资产／切换；不能通过网页操作完整八回合。普通牌堆耗尽规则等既有待确认项不新增解释。未连接用户服务器或部署，原生PostgreSQL／真实账户仍在后续。继承此前浏览器策略拒绝，没有再尝试或绕过，点击／截图／视觉验收未完成；实际自动验证见[记录](testing/construction-ui-validation-2026-10-28.md)。
