# 基础版设施卡面转录 · 2026-10-22

这是已提供照片的结构化转录，供继续核对与开发使用。当前状态为 `mixed-source-transcription`：18 份风味全文及联邦理事处/核心指挥塔的完整说明来自负责人本次原文，按字段记为 `user-provided`；其余效果区、分数/费用保留图片转录来源，不借此宣称全部数值也获用户确认。本文不声明完整建设规则或设施效果执行器已经实现。

基础版共有 18 种、48 张设施。此模块只记录每种设施**照片中可见的一张卡面**，`appliesTo=pictured-face-only`；不据此断言不同颜色版本一定有相同费用和效果。分颜色实体张数仍由独立的数量模块保存，不复制为费用、格数或布局。

## 已设计、已实现

`founders-faces.json` 格式 2.0.0 保存分数、普通费用的两种替代支付方式、入场/唯一标识、按顺序的文字/图标片段、逐字段文字来源、风味全文、规则书图标含义和逐张图片位置。旧 1.0.0 转录格式不静默视为新确认文本。Zod 严格校验、基础版身份/颜色交叉校验、不可变加载、固定基准 SHA-256、查询与进度统计已实现。根模块及 `/facilities` 子路径均导出。

费用是“资源组合 **或** 金券”，资源组合本身可以包含金券。例如物流枢纽为 1 至纯源石 + 2 金券 **或** 24 金券；佣兵指挥部为 2 源岩 + 2 异铁 + 4 金券 **或** 18 金券。核心指挥塔及延伸枢纽卡面未印普通费用，使用 `not-printed`，没有编码为 0 费或允许普通建设。

图标保留视觉 token、重复次数和顺序，同时通过 iconLegend 对应规则书术语。getFacilityIconMeaning / getFacilityEffectText 可查询含义或输出可读效果。此前只写外观标签而未核对动作，且将佣兵指挥部的红绿双箭头漏读成单红箭头，已更正为“替换1个影响力”。这些含义不自动授予行动额度、选择目标或改变权威状态。唯一标识依据规则书 p07：已拥有同名设施时不能再建设该牌。入场标识与唯一标识分开记录，不能把“唯一”误读为持续效果。城邦工业区的折扣文字与其没有入场标识的事实同时保留，不提前编写执行时机。

正文转录去除排版换行及加粗，图标和表格用线性片段保存；图标表格的冒号/分号及数字周围空格为阅读分隔，不声称逐字复刻印刷排版。风味文字与规则效果分开，无法可靠辨认的字不补猜。

## 行动图标及数量边界

| 图示 | 规则含义 | 依据（规则书印刷页） |
| --- | --- | --- |
| 红色上箭头方块 | 放置1个影响力 | p05 部署图示 |
| 蓝色右箭头方块 | 移动1个影响力 | p06 调度图示与说明 |
| 绿色下箭头方块 | 移除1个影响力 | p14 雷蛇移除/替换说明与卡面图示对照 |
| 红绿双向箭头方块 | 替换1个影响力 | p07 佣兵指挥部示例，p14 雷蛇计谋的替换定义 |
| 城市右箭头 | 城市移动 | p07 城市移动 |
| 起重机 | 建设 | p07 建设 |

规则书 p05–07 的六类主要行动是部署、调度、探索、城市移动、建设、特殊行动。**单个蓝色右箭头只表示移动1个影响力；一次调度主要行动执行两次移动**，不能把设施的一个图标自动放大成整个主要行动。载具仓库依顺序放置1个、移动1个，或改为探索；护航调度中心保留两次移除；佣兵指挥部为替换或移除；简陋工程营为建设，卡面没有“免费”，不能擅自免建造费。具体目标、可否放弃、费用和入场链仍由后续执行器按完整规则处理。
