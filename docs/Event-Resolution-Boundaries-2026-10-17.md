# 基础事件的结算边界核对与静态数据实现

日期：2026-10-17。依据：基础规则书印刷 p04–07、p12–13，以及项目负责人已确认的 22 张事件牌文本与数值。没有使用企业扩展或《感染者》规则。

## 本次实际范围

本次实现独立事件静态目录、Zod Schema、完整性与固定内容摘要校验、只读查询和测试。沿用 TypeScript strict、Zod、Vitest 与既有 workspace；没有改动 Accepted ADR-0001、地图定义、动态 BoardState 或技术栈。

本模块描述每个选项的效果数据，但没有执行器、玩家余额、行动阶段、事件牌堆洗牌/抽取、客户端写状态接口、UI 或联机。没有宣布完整规则引擎或 v0.3.0 完成，也没有新建发布版本。

## 从规则原文已经能确定的事项

| 事项 | 依据 | 对数据与后续实现的约束 |
| --- | --- | --- |
| 初始事件 | p04 初始资源点 | 起始放置城市、揭示绿色事件并选择一个选项；不能把探索行动的整套费用流程自动套到开局 |
| 探索顺序 | p06 探索三步骤 | 支付路费、结算事件、目标资源点放置影响力是分开的步骤；事件本身的额外放置不能代替或吞掉末尾步骤 |
| 城市移动 | p06–07 城市移动 | 清除相关对手影响力发生在必要的事件结算之前，事件后另有目标点放置步骤；不能拿移动前槽位状态替代实际结算时状态 |
| 影响力放置 | p05 部署和定义 | 每次使用一个玩家标记；目标空槽；资源点还要求已探索且没有其他玩家城市；牌面的范围约束另外保留 |
| 顺序与尽量执行 | p13 执行的顺序 | 按从左到右、从上到下执行；某些部分无法执行时，不能未经规则依据撤销已经完成的其他部分 |
| 条件式费用 | p13 条件式效果 | 箭头之前须完整执行才能执行之后；可选择不执行前置并结束该效果；不能把 Y05 的 4 金券写成可部分支付或强制自动扣款 |
| 支付后的效果 | p13 条件式效果第 3 点 | 完成前置后，后续仍按“尽量执行”；不自行引入退款或数据库式整笔回滚规则 |
| 缺少标记 | p13 没有足够的指示物 | 金券及至纯源石可用替代物；玩家标记有数量限制，不足时不能继续放置影响力或宣告样式；不能为其自动创造新标记 |
| 红牌 ×2 | p12 特殊资源点 | 是资源指示物/采集量，不将牌面即时奖励整体翻倍 |

上述内容是规则核对，尚未由行为测试证明某个结算执行器正确。涉及行动与事件的组合仍需要明确的对局状态和逐案例测试；不应仅凭静态目录验证成功就认定行动合法。

| 牌/选项 | 本次静态表示 | 未来行为测试要点 |

工程上采用三个范围名称：`standard`、`incident-route`、`event-node-or-incident-route`。这是对已确认牌面范围的技术标识，不新增移动距离或替换权限。`cost: null` 表示牌面没有条件费用，不代表后续任何效果都必定可执行。

## 数据目录与摘要

- `packages/game-core/src/events/founders-base.json` 保存 22 张基础牌、49 个选项，包含已确认描述、对白、资源指示物、四人图标、成本及效果。
- `schema.ts` 严格解析并检查 ID、牌色、完整 ID 集合、选项归属与顺序；嵌套数据为只读且冻结的解析副本，不冻结调用者输入。
- `catalog.ts` 的完整验证要求内容摘要与独立固定的批准基准均一致。修改数值后重算输入摘要仍被拒绝；Schema 单独通过只说明结构有效。
- 元数据固定确认日期、两个来源文档的文件字节 SHA-256 和读取的 Git 提交 `e29b00ee6285515e8a432ed18938bd07193598b7`。确认来自项目负责人，不冒充发行方认证。
- 来源表内的 G/Y/R 与 S1–S4 是工程索引。四人标识只作为原始事实保存，尚未实现两人/三人牌堆准备。两张 E 替换牌未纳入目录。

事件摘要协议为 `nco-events-c14n-v1`，封装为 `{hashProtocol, catalog}`。包括 catalog 的全部字段，只有顶层 `contentHash` 自身被排除。递归按 JS 默认 `.sort()` 的 UTF-16 顺序排序对象键，**所有数组保留顺序**，因此牌序、选项顺序和效果顺序均进入摘要。字符串不做 trim/NFC/空格变换；紧凑 JSON、无末尾换行，以 UTF-8 送入 SHA-256，输出 `sha256:` + 64 位小写十六进制。

不能复用将 ID 数组视为无序集合的地图哈希协议。事件摘要是内容一致性检查，不是签名或客户端授权。

当前固定摘要：`sha256:aada5d9e8cb65c18897fca37eb0935e1cc4d38e848aab4fa6f3e64031d8e2ca7`。
