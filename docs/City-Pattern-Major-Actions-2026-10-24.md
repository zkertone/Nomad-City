# 三张城市样式：额外主要行动与角色例外

基础版二、三、四人接入源石工业中枢、核心商业区、拓荒指挥中枢。显式升级GameState1.15.0后，基础目录13种宣告、10种特殊行动全部可执行；企业/企业家完整配置、临时聚居点与最终计分提交仍待实现。三档版本与人数仍是独立维度，不表示九种组合均已完成。

## 卡面规则

依据负责人提供的image(6)/(7)卡面和《铸基者》主要行动、快速行动、角色规则。15张原始卡面文字、风味、图案与固定摘要均保留。

| 样式 | 特殊行动 | 本行动轮的角色限制 |
| --- | --- | --- |
| 源石工业中枢 PAT-003 | 一次支付6金券，额外执行两次主要行动；两次之间可以使用合法快速行动 | 不能使用角色，包括嵌套指挥中枢后 |
| 核心商业区 PAT-008 | 先获得4金券或1个自选基础资源，再执行一次非特殊主要行动 | 沿用原角色权限 |
| 拓荒指挥中枢 PAT-010 | 执行一次非特殊主要行动 | 本行动轮非起始玩家也能对自己盖放的同一张初始角色执行策略→计谋 |

工业中枢原文没有另外两张的“特殊行动以外”限制，因此其子行动可执行已支持的特殊行动，包括商业区或指挥中枢。后两张的子行动不能再次选择特殊行动。所有样式仍遵守玩家×样式本回合使用限制；角色仍只能使用一次，双模式不是第二次角色使用，不涉及干员获得或使用规则。

奖励在商业区开启时实际入账，可支付之后的合法行动费用；没有提前透支未来收入。工业中枢费用只付一次，取消子行动准备不会退款、返还样式次数或重发奖励。

## 接口与完成顺序

`enableCityPatternMajorActions(state, definition, { expectedVersion })`只接受已验证1.14.0，升级为1.15.0并添加空的`cityPatternMajorActions`。升级保留当前行动、1.14续接、余额、角色和样式历史，不推造旧存档事实。各命令沿用对局、身份和版本校验。

`applyCityPatternCommand`使用新增效果：

```typescript
{ kind: 'industry-actions' }
{ kind: 'commercial-action', reward: 'columbia-voucher' } // 或orirock/originium/iron
{ kind: 'command-action' }
```

外层特殊行动消耗当前正常主要行动额度；随后用原部署、调度、探索、移城、建设命令执行额外行动。`getRoundTurn`在待选择子行动时返回not-started，开启后按实际进度返回pending或complete，并在新格式中提供`patternActions`。玩家不能传入额外次数、折扣、免费标识或虚构完成状态。

每个子行动及其事件、设施嵌套入场、样式续接完整结束后，提交受管回合命令`finish-pattern-action`消耗一个额外行动名额。序列结束自动移除对应记录；嵌套商业区/指挥中枢完整结束只消耗工业中枢的一个名额。所有序列结束后，原主要行动登记为special完成，再按原流程`finish-player-turn`。仍有序列时不能结束玩家行动轮。

角色和宣告只可在子行动前或完整完成后的快速行动窗口执行，不能越过未完成事件、建设入场、移城或样式续接。新兴建筑群宣告建设在前后窗口正确恢复子行动额度；城区管理中心归还正在执行的商业区标记，不会撤销已经实际授予的行动或再次发奖。

`cancel-major-preparation`只撤回未进行任何实际步骤的普通子行动准备，保留外层费用、样式次数与正常主要行动已开启的事实；不能取消外层序列或已开启特殊行动。保存后恢复每个等待选择点，不会重复扣费、奖励、使用角色或消费名额。

## 权威状态与兼容

`cityPatternMajorActions`保存最多两层序列的patternId、remainingActions、activeAction、activePatternId。每层必须对应当前玩家在本行动轮的真实公开样式使用记录；只有工业中枢可以拥有特殊子行动。普通子行动的种类、完成记录和现有顶层进度互相校验，不复制经济、地图、角色或设施账本。

指挥中枢双模式权限来自本玩家、本行动轮的PAT-010实际使用记录，即使额外行动完成后仍可在本行动轮合法窗口使用；不会带入下一轮玩家行动。角色历史验证使用其实际使用时的turnIndex，推进回合后不会错误判为无权。工业中枢的本轮角色禁令优先。

旧1.0.0–1.14.0继续按原能力读取，拒绝伪造新字段。`getCityPatternActionSupport(state.schemaVersion)`应传入实际版本：默认1.13.0保留12宣告/4特殊行动兼容结果，1.14.0为13/7，1.15.0为13/10且`allBasePatternActionsImplemented=true`；全体15张的`allPatternActionsImplemented`仍为false。

本批是纯规则核心，没有UI、联机、认证、数据库事务或部署。未来服务端仍需串行比较并提交版本，私有完整状态不能直接广播。实际测试与编译流程见[验证记录](testing/city-pattern-major-actions-validation-2026-10-24.md)。
