## 可执行模块范围

`packages/game-core/src/facilities/` 提供不可变颜色记录、Zod Schema、唯一 ID/名称检查、固定基准校验、SHA-256 内容摘要和只读查找。状态明确为 user-confirmed-colors-only。允许加载这批已确认颜色事实，不等于设施完整规则已经实现。

记录中不设置 cost/score/effect/footprint 等字段；未核对的字段保持未建模，不以 0 或空效果代替。`FOUNDERS_FACILITY_COPY_COUNT_CONFIRMATIONS` 与 `getConfirmedFacilityCopyCount` 单独保存/查询核心指挥塔数量；其他名称返回 null。该确认只记录物理卡数量，不初始化权威设施牌库或改变标记账本。

支持根模块和 `/facilities` 子路径导入。现有 GameDefinition/GameState、地图/事件摘要、已确认文案和 Accepted ADR 保持原值。

## 内容摘要协议

协议名 nco-facility-colors-c14n-v1。哈希覆盖 schemaVersion、catalogId、verificationStatus、sourceRefs 和全部设施 id/name/colorCellCounts，排除 contentHash；将 facilities 按项目 ID 升序排序，递归按对象键名排序，JSON 不加空白，以 UTF-8 编码后计算 SHA-256。来源数组顺序保留，JSON 保留中文字符；校验按 Schema 输出计算摘要（名称先去除两端空白），不进行 Unicode 归一化。仅对象键序与设施列表原序不影响摘要。

已确认基准固定在代码中，与数据自己声明的 contentHash 分开。篡改颜色后即使自行重算摘要，也不能通过这份已确认基准校验。当前基准：

`sha256:6f036e1907f2eefe6b6cbb5f6a0ee1d01b0552e76da8581e567862e5e76e066a`
