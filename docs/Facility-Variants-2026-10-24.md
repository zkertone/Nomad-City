# 基础设施同名卡跨颜色规则 · 2026-10-24

## 规则依据与范围

负责人于2026-10-24明确确认：“同名卡数据是一样的，只有颜色有区别”。适用于现有《铸基者》基础设施目录的相同facilityId，不扩展到E/O扩展或未收录牌。`FACILITY_COLOR_VARIANT_RULE` 独立保存来源、日期和原文；原照片JSON、observedColor及固定摘要保留，不将此确认伪记为新照片。

| 新解除限制的实体 | 共用规则 |
| --- | --- |
| 蓝色异铁冶炼厂 | 与红色同名卡相同费用、1分、获得4异铁 |
| 黄色源石精炼厂 | 与蓝色同名卡相同费用、0分、获得6源石 |
| 红色固源岩提纯厂 | 与黄色同名卡相同费用、0分、获得7固源岩 |
| 红色、蓝色延伸枢纽 | 与黄色同名卡相同，仅物流授权从预留区建设，-1分，无普通建设费用 |

普通建设16类41张，延伸枢纽3张，初始核心4张，共18类48张。实体牌ID、颜色、数量、归属和格位保持原定义。

## 执行与存档

- 普通建设按facilityId查询唯一卡面数值，不再以observedColor拒绝其他已登记颜色。支付前库存校验、唯一设施限制、立即补牌、摆放、分数、入场和失败原子性沿用原实现。
- 物流候选包含预留区全部剩余延伸颜色；命令仍验证预留区归属、空格和版本，不能普通建设延伸枢纽，也不能重复领取。
- 已建颜色版本的存档校验、能源复制及工程营候选共用此规则，不再出现建设成功却无法载入或复制的差异。GameState格式仍1.12.0，无新增存档字段或迁移。
- 工业区按实际实体颜色去重：同名红/蓝计2色，不同名同红只计1色；能源只复制实际非虹色十字相邻设施。

`getFacilityConstructionSupport()` 当前普通41张、特殊延伸3张、unconfirmedPhysicalCardIds为空，提供colorVariantRule，allFacilitiesImplemented=true表示当前基础设施类型及颜色均有执行路径。完整游戏、普通牌堆耗尽规则、城市样式/特殊行动、最终计分提交、联机与UI仍待完成。静态照片转录executionReady不用于表示运行能力。
